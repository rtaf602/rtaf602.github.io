# สถานภาพอากาศยาน ฝูง.602 บน.6

หน้าเว็บ `https://rtaf602.github.io` ล็อกอินผ่าน Google Apps Script ซึ่งอ่าน Google Sheet แทนหน้าเว็บ

```
เบราว์เซอร์ (rtaf602.github.io)  ──JSON──>  Apps Script Web App  ──>  LOGIN DATABASE
                                                                  ──>  HISTORY LOGIN DATA
                                                                  ──>  HISTORY ACTION DATA
```

หน้าเว็บไม่เคยได้รับ Salt, Hash, วันเกิด หรือหมายเลขบัตร ได้รับกลับมาแค่ผลผ่าน/ไม่ผ่าน, token และชื่อกับ Role ของผู้ที่ล็อกอินผ่าน

## ไฟล์

| ไฟล์ | อยู่ที่ไหน |
|---|---|
| `index.html` | repo `rtaf602.github.io` (หน้าเว็บทั้งหมด: ล็อกอิน, DASHBOARD, หน้าย่อย) |
| `apps-script/Code.gs` | วางในหน้า Apps Script เท่านั้น **ห้ามขึ้น repo** เพราะมีรหัสไฟล์ Google Sheet ทั้งสามไฟล์ (เหมือนส่วน `SETUP` ของระบบ eadmin602) |
| `apps-script/appsscript.json` | วางในหน้า Apps Script |

## Google Sheet ที่ใช้

| ไฟล์ | แท็บ | เนื้อหา |
|---|---|---|
| LOGIN DATABASE | `DATABASE LOGIN` | บัญชีผู้ใช้ อ่านอย่างเดียว ระบบนี้ไม่แก้ไฟล์นี้ |
| HISTORY LOGIN DATA | `HISTORY LOGIN DATA` | ประวัติ Login / Logout / ล็อกอินไม่ผ่าน / หมดเวลา / เข้าสู่ระบบซ้อน |
| HISTORY LOGIN DATA | `HISTORY LOGIN MAIN PAGE` | สถานะบัญชี: ACTIVE, SUSPENDED, BLOCKED และช่องติ๊กปลดล็อก |
| HISTORY ACTION DATA | `HISTORY ACTION DATA` | ประวัติการกด แก้ไข, บันทึก, ส่งแบบฟอร์ม, Export PDF, Export Excel |

ระบบหาคอลัมน์ในแท็บ `DATABASE LOGIN` จากชื่อหัวตาราง (แถวแรกที่มีคำว่า `Username`) ย้ายคอลัมน์ได้ แต่อย่าเปลี่ยนชื่อหัวตาราง

| หัวตาราง | ใช้ทำอะไร |
|---|---|
| `ยศ`, `ชื่อ-สกุล` | ชื่อที่แสดงในประวัติ |
| `ID Card ขรก.` | ตรวจหมายเลขบัตรข้าราชการ (เทียบเฉพาะตัวเลข ไม่สนเลข 0 นำหน้า) |
| `BIRTH DATE` | ตรวจวันเกิด ในชีทเป็น ค.ศ. ผู้ใช้เลือกเป็น พ.ศ. ระบบลบ 543 ก่อนเทียบ |
| `Role` | `Admin` หรือ `Editor` (ใช้ได้ทุกปุ่ม), `Viewer` (ดูอย่างเดียว) ถ้าว่างหรือเป็นค่าอื่น ล็อกอินไม่ได้ |
| `Username` | ผู้ใช้พิมพ์เอง ไม่สนตัวพิมพ์ใหญ่เล็ก ต้องไม่ซ้ำกัน |
| `Salt`, `hash` | ตรวจรหัสผ่านด้วย PBKDF2-HMAC-SHA256 5,000 รอบ (ค่าเดียวกับระบบ eadmin602) |
| `วันสิ้นสุดการใช้งาน` | ถ้าเลยวันนี้แล้ว บัญชีล็อกอินไม่ได้ |

แถวที่ช่อง Username ว่าง หรือเขียนว่า `Username` (แถวหัวตารางของแต่ละกลุ่ม) ระบบข้ามไป

## ติดตั้ง

ทำด้วยบัญชี Google ที่เป็นเจ้าของหรือแก้ไขได้ทั้ง 3 ไฟล์ และตั้งการแชร์ทั้ง 3 ไฟล์เป็น "จำกัด"

### 1. ใส่โค้ด Apps Script

1. เปิดไฟล์ **HISTORY LOGIN DATA** แล้วเลือก **ส่วนขยาย > Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางโค้ดจาก `apps-script/Code.gs`
3. ไปที่ **การตั้งค่าโปรเจกต์** (รูปเฟือง) ติ๊ก **แสดงไฟล์ Manifest "appsscript.json" ในตัวแก้ไข** แล้วกลับไปวางเนื้อหาจาก `apps-script/appsscript.json`
4. กดบันทึก แล้วรีเฟรชหน้าชีท HISTORY LOGIN DATA จะมีเมนู **ระบบล็อกอิน ฝูง.602**

### 2. อนุญาตสิทธิ์และตั้งตัวล้าง session

1. เลือกเมนู **ระบบล็อกอิน ฝูง.602 > ติดตั้งตัวล้าง session อัตโนมัติ (ทำครั้งเดียว)**
2. Google จะขออนุญาตให้สคริปต์อ่านและเขียนชีท กดอนุญาต ถ้าขึ้นว่า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง > ไปที่ (ชื่อโปรเจกต์)** เพราะเป็นสคริปต์ของหน่วยเอง

### 3. ตรวจค่า PBKDF2 (ทำเมื่อรหัสถูกแต่ล็อกอินไม่ผ่าน)

`CONFIG.PBKDF2_ITERATIONS` ตั้งไว้ 5,000 ตาม SETUP_TH ของระบบ eadmin602 ถ้าใช้บัญชีที่รู้รหัสแล้วล็อกอินไม่ผ่าน และคอลัมน์ "สาเหตุ" เป็น `WRONG: PASSWORD`:

1. เลือกเมนู **ระบบล็อกอิน ฝูง.602 > ตรวจหาค่า PBKDF2 จากบัญชีทดสอบ**
2. ใส่ Username และรหัสผ่านของบัญชีที่ทราบรหัส (รหัสผ่านใช้คำนวณเท่านั้น ไม่ถูกบันทึก)
3. ระบบจะลองทุกจำนวนรอบตั้งแต่ 1 ถึง 2,000,000 และแสดงค่าที่ตรงกัน
4. นำค่าไปใส่ใน `CONFIG` ที่ต้นไฟล์ `Code.gs` แล้วบันทึก

### 4. Deploy เป็น Web app

1. ใน Apps Script กด **ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้รายการใหม่**
2. ประเภท **เว็บแอป**, ดำเนินการในฐานะ **ฉัน**, ผู้ที่มีสิทธิ์เข้าถึง **ทุกคน**
3. กด Deploy แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
4. เปิด URL นั้นในเบราว์เซอร์ ต้องเห็น `{"ok":true,"service":"sqn602-auth"}`

"ทุกคน" หมายถึงทุกคนเรียก URL นี้ได้ ซึ่งจำเป็นเพราะหน้าเว็บต้องเรียกก่อนล็อกอิน ทุกคำขอยังต้องผ่านการตรวจของสคริปต์

### 5. ใส่ URL ในหน้าเว็บ

1. เปิด `index.html` หาบรรทัด `const API_URL='';` แล้วใส่ URL จากขั้นที่ 4 ไว้ในเครื่องหมาย `'...'`
2. ส่งขึ้น repo `rtaf602.github.io` ผ่าน Pull Request ตามกฎของ branch `main`
3. ถ้า `API_URL` ว่าง หน้าเว็บจะอยู่ในโหมดตัวอย่าง (Username `demo`, `demo-viewer`, `demo-wait`) ซึ่งไม่ได้ป้องกันข้อมูลจริง

### 6. ทดสอบก่อนใช้งานจริง

- [ ] ล็อกอินด้วยบัญชีจริงผ่าน และมีแถว `LOGIN_OK` ใน HISTORY LOGIN DATA
- [ ] ใส่ข้อมูลผิดแต่ละช่อง ได้ข้อความเดียวกันทุกครั้ง และคอลัมน์ "สาเหตุ" บอกช่องที่ผิด
- [ ] ใช้บัญชีทดสอบ กรอกผิด 5 ครั้ง สถานะเป็น `SUSPENDED` และกรอกถูกก็ยังเข้าไม่ได้จนครบ 60 นาที
- [ ] หลังพัก กรอกผิดอีก 5 ครั้ง สถานะเป็น `BLOCKED`
- [ ] ติ๊กช่อง "ปลดล็อก" แล้วบัญชีกลับเป็น `ACTIVE` และมีแถว `ADMIN_UNLOCK`
- [ ] กดปุ่มแก้ไข / บันทึก / Export และส่งแบบฟอร์ม แล้วมีแถวใน HISTORY ACTION DATA
- [ ] บัญชี Viewer กดแก้ไขหรือบันทึกไม่ได้
- [ ] บัญชีที่ Role ว่าง หรือยังเป็น `User` ล็อกอินไม่ได้ และคอลัมน์ "สาเหตุ" เป็น `ROLE_NOT_SET` หรือ `ROLE_UNKNOWN: User`
- [ ] เปิดสองแท็บในเบราว์เซอร์เดียวกัน: แท็บที่สองเข้าได้เลยด้วยบัญชีเดียวกัน กดออกจากระบบแท็บหนึ่ง อีกแท็บกลับหน้าล็อกอิน
- [ ] ล็อกอินบัญชีเดียวกันจากอีกเครื่อง: เครื่องเดิมขึ้นนับถอยหลัง 10 วินาทีพร้อมปุ่ม "ไม่อนุญาต ฉันกำลังใช้งานอยู่" ภายในราว 10 วินาที เครื่องที่สองขึ้น "กำลังรอเครื่องเดิมออกจากระบบ"
- [ ] ลองทั้งแบบกดไม่อนุญาต (มีแถว `LOGIN_DENIED`) และแบบปล่อยให้ครบเวลา (มีแถว `SESSION_REPLACED` และ `LOGIN_OK` "เข้าแทนเครื่องเดิม")
- [ ] เปลี่ยน Role จาก Editor เป็น Viewer ระหว่างล็อกอินอยู่ ภายในราว 20 วินาทีปุ่มแก้ไขกดไม่ได้
- [ ] กดออกจากระบบ มีแถว `LOGOUT`
- [ ] เปิดหน้าเว็บ กด F12 > Network แล้วดูคำตอบของการล็อกอิน ต้องไม่มี Salt, Hash, วันเกิด หรือหมายเลขบัตร

## งานของผู้ดูแล

| ต้องการ | ทำอย่างไร |
|---|---|
| ปลดบัญชีที่ถูกพักหรือถูกบล็อก | แท็บ `HISTORY LOGIN MAIN PAGE` ติ๊กช่อง "ปลดล็อก" ในแถวของบัญชีนั้น ระบบตั้งเป็น ACTIVE, ล้างจำนวนครั้งที่ผิด, บันทึกผู้ปลดและเวลา แล้วเอาเครื่องหมายติ๊กออกเอง |
| ระงับบัญชีทันที | เปลี่ยนคอลัมน์ "สถานะ" ของบัญชีนั้นเป็น `BLOCKED` เครื่องที่ล็อกอินค้างอยู่ออกจากระบบภายในราว 20 วินาที |
| ปิดบัญชีถาวร | ใส่วันในคอลัมน์ `วันสิ้นสุดการใช้งาน` หรือลบค่าในคอลัมน์ `Role` ของ LOGIN DATABASE มีผลภายในราว 20 วินาที |
| เปิดให้บัญชีใหม่ใช้งาน | ใส่ `Admin`, `Editor` หรือ `Viewer` ในคอลัมน์ `Role` |
| ให้ทุกคนออกจากระบบ | เมนู **ระบบล็อกอิน ฝูง.602 > ให้ทุกคนออกจากระบบทันที** |
| แก้โค้ด Apps Script | แก้แล้วบันทึก จากนั้น **Deploy > จัดการการทำให้ใช้งานได้ > แก้ไข (ดินสอ) > เวอร์ชัน: เวอร์ชันใหม่** URL เดิมยังใช้ได้ |

บัญชีจะมีแถวในแท็บ `HISTORY LOGIN MAIN PAGE` หลังจากมีการล็อกอินด้วย Username นั้นครั้งแรก

## กติกาการล็อกอิน

- ไม่ผ่านทุกกรณี หน้าเว็บแสดง "ข้อมูลไม่ถูกต้อง หรือบัญชียังไม่พร้อมใช้งาน กรุณาติดต่อ Admin" สาเหตุจริงบันทึกไว้ให้ผู้ดูแลดูในคอลัมน์ "สาเหตุ" เท่านั้น
- ผิดติดกัน 5 ครั้ง พัก 60 นาที ระหว่างพักกรอกถูกก็เข้าไม่ได้ และไม่นับเพิ่ม (ระบบ eadmin602 พัก 15 นาที สองระบบนับแยกกัน)
- หลังพัก ผิดติดกันอีก 5 ครั้ง บล็อกจนกว่าผู้ดูแลจะปลด
- ล็อกอินผ่านเมื่อไร จำนวนครั้งที่ผิดและรอบการพักกลับเป็นค่าเริ่มต้น
- Username ที่ไม่มีในระบบบันทึกเป็น `UNKNOWN_USERNAME` แต่ไม่ถูกนับหรือล็อก
- บัญชีที่ Role ว่างหรือไม่ใช่ `Admin` / `Editor` / `Viewer` ล็อกอินไม่ได้ บันทึกเป็น `ROLE_NOT_SET` หรือ `ROLE_UNKNOWN`
- ทุกคำขอล็อกอินใช้เวลาตอบใกล้เคียงกัน เพื่อไม่ให้ใช้เวลาเดาว่ามี Username นั้นหรือไม่

## Session และการเข้าสู่ระบบซ้อน (กติกาเดียวกับระบบ eadmin602)

- **ล็อกอินหนึ่งครั้งใช้ได้ 1 ชั่วโมง** นับจากเวลาที่ล็อกอิน ไม่ต่ออายุตามการใช้งาน หน้าเว็บเตือนก่อนหมดเวลา 5 นาที ครบแล้วออกจากระบบเอง
- **หนึ่งเบราว์เซอร์ล็อกอินได้หนึ่งบัญชี** ทุกแท็บของเบราว์เซอร์เดียวกันใช้การล็อกอินเดียวกัน และยังล็อกอินอยู่แม้ปิดแท็บ จนกว่าจะกดออกจากระบบหรือครบ 1 ชั่วโมง จะเข้าบัญชีอื่นต้องกดออกจากระบบก่อน เครื่องที่ใช้ร่วมกันต้องกดออกจากระบบทุกครั้ง หน้าต่างส่วนตัว (Incognito / InPrivate) ถือเป็นอีกเบราว์เซอร์หนึ่ง
- **หนึ่งบัญชีใช้ได้คราวละหนึ่งเครื่อง** หน้าเว็บที่ล็อกอินอยู่ถามระบบทุก 10 วินาที ถ้ามีการล็อกอินบัญชีเดียวกันจากเครื่องอื่น เครื่องเดิมมีเวลา 10 วินาทีให้กด "ไม่อนุญาต ฉันกำลังใช้งานอยู่" ถ้าไม่กด เครื่องเดิมออกจากระบบและเครื่องใหม่เข้าแทน
- ถ้าเครื่องเดิมไม่ได้ถามระบบเกิน 30 วินาที ระบบถือว่าไม่ได้เปิดหน้าเว็บอยู่ และให้เครื่องใหม่เข้าได้ทันที เบราว์เซอร์ชะลอการทำงานของแท็บที่ไม่ได้เปิดดูอยู่ แท็บที่ถูกพับไว้นานจึงอาจถูกนับว่าไม่ได้เปิดหน้าเว็บ
- **เปลี่ยนรหัสผ่าน (Reset Password จากระบบ eadmin602)** เครื่องที่ล็อกอินค้างด้วยรหัสเดิมออกจากระบบภายในราว 10 ถึง 20 วินาที
- เปลี่ยน Role ระหว่าง Admin / Editor / Viewer มีผลกับเครื่องที่ล็อกอินอยู่ภายในราว 20 วินาที โดยไม่ต้องล็อกอินใหม่
- ถ้าปิดเว็บโดยไม่กดออก ระบบบันทึก `SESSION_EXPIRED` เมื่อครบเวลา (ตัวล้างทำงานทุก 15 นาที)

## ข้อจำกัดที่ทราบ

- Apps Script ไม่เห็นหมายเลข IP ของผู้ใช้ ประวัติจึงบันทึกได้แค่อุปกรณ์/เบราว์เซอร์ ซึ่งเป็นค่าที่เบราว์เซอร์ส่งมาเอง
- การถามระบบทุก 10 วินาทีของทุกหน้าที่ล็อกอินอยู่ เพิ่มจำนวนคำขอที่ Apps Script ต้องรับ ถ้าคนใช้พร้อมกันมาก การตอบอาจช้าลง
- ปุ่มแก้ไข, บันทึก, Export PDF และ Export Excel ตอนนี้บันทึกประวัติการกดอย่างเดียว ยังไม่มีฟังก์ชันจริง
